# Changelog

## 1.0.0

- Experimental pipeline for Turkish–Kazakh sentiment classification, including
  lexical models, frozen embeddings, XLM-R fine-tuning and zero-shot Qwen3-8B.
- Pinned dataset/model revisions, recorded dependency versions and supplementary methods.
- Aggregate evaluation results, paired statistical analyses and figure source data.
- Offline result verification, input-preparation utilities and synthetic tests.
- MIT license and software citation metadata.

The experimental scripts and numerical results retain their original checksums.
See [Known issues](docs/KNOWN_ISSUES.md) for implementation notes.
