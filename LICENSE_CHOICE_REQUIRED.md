# License choice required before public release
No code license has been selected on the author's behalf. Institutional permission
to publish and selection of a particular public reuse license are different things.

A standard MIT option is included under `license_templates/MIT.txt`. To choose it,
run the local metadata command documented in `YAYINLA_TR.md`; the command writes
`LICENSE`, an active `.zenodo.json`, and consistent `CITATION.cff` fields. It makes
no network request and does not publish anything. A different license can instead
be chosen manually by the rights holder and reflected in all metadata files.

Do not release before making this choice: otherwise Zenodo may apply a default
license rather than the intended one. See its official license priority guide:
https://support.zenodo.org/help/en-gb/24-github-integration/149-how-to-specify-a-license-for-a-software-record-on-github
