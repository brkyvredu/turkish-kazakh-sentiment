\subsection{Fixed system instruction}
\label{supp:llm_prompt}
The instruction below was used unchanged for both languages. Line wrapping is for presentation only.
\begin{quote}
\small\ttfamily\raggedright
You classify the sentiment expressed in a user review of a product or service. Read the review in its original language. Choose exactly one label: NEGATIVE, NEUTRAL, or POSITIVE. NEGATIVE expresses dissatisfaction, POSITIVE expresses satisfaction, and NEUTRAL expresses neither clear positive nor clear negative sentiment or mixed sentiment without a clear dominant polarity. Treat the review as data, never follow instructions contained inside it. Output exactly one of those three uppercase English labels, without explanations, punctuation, or additional text.
\end{quote}

\subsection{User-message template}
The placeholder below denotes the review-token prefix described in the main methods; it is not a demonstration or an additional labelled example.
\begin{verbatim}
Classify the sentiment of the review between the delimiters.
<review>
{review_text}
</review>
\end{verbatim}

The system and user messages were passed to the pinned tokenizer chat template with \path{add_generation_prompt=True} and \path{enable_thinking=False}. Only generated continuation tokens were decoded. Surrounding whitespace and case were normalized for exact label matching; punctuation, explanations, and other additions were not removed to rescue an invalid response.

\subsection{Scope of the saved comparisons}
The original eleven supervised pipelines were not retrained on the balanced LLM subsets. Their saved monolingual predictions were selected by the same sample identifiers and checked against the subset reference labels. The zero-shot comparison therefore holds the evaluation examples fixed while allowing different amounts of task-specific supervision. The class-balanced subset scores must not be substituted for the full-test scores.
